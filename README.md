# Media Academy Cloud

نظام سحابي لإدارة أكاديمية كلية الإعلام، مبني باستخدام Google Apps Script وGoogle Sheets وHTML وCSS وJavaScript.

## المميزات

- إدارة بيانات الطلاب.
- تنظيم المحتوى التعليمي حسب الفرقة.
- إعداد المحاضرات ومواعيدها.
- تسجيل الحضور باستخدام GPS.
- متابعة الحضور المباشر.
- أرشفة سجلات الحضور بصيغة CSV.
- نشر الإعلانات للطلاب.
- استقبال الشكاوى ومتابعتها.
- لوحة تحكم للإدارة والطلاب.
- واجهة متجاوبة مع الهواتف والأجهزة المختلفة.

## التقنيات المستخدمة

- Google Apps Script
- Google Sheets
- Google Drive
- HTML5
- CSS3
- JavaScript

## ملفات المشروع

| الملف | الوظيفة |
|---|---|
| `Code.gs` | الخادم وقاعدة البيانات والوظائف الرئيسية |
| `Index.html` | الصفحة الرئيسية |
| `Styles.html` | التصميم والألوان |
| `Client.html` | وظائف الواجهة والتفاعل |
| `appsscript.json` | إعدادات مشروع Apps Script |
| `README.md` | توثيق المشروع |

## طريقة التشغيل

1. أنشئ Google Sheet جديدًا.
2. افتح Extensions ثم Apps Script.
3. أنشئ ملفات المشروع وانسخ الأكواد من مستودع GitHub.
4. شغّل الدالة `setupSystem()` مرة واحدة.
5. وافق على الصلاحيات المطلوبة.
6. من Apps Script اختر Deploy ثم New deployment.
7. اختر Web app واضبط صلاحيات الوصول المناسبة.
8. اضغط Deploy وافتح رابط التطبيق.

## قاعدة البيانات

يقوم النظام بإنشاء أوراق البيانات التالية داخل Google Sheets:

- الطلاب
- محتوى الفرق
- إعدادات المحاضرات
- الحضور الحي
- الأرشيف
- الإعلانات
- الشكاوى

## ملاحظات أمنية

- غيّر كلمة مرور الإدارة الافتراضية فور إعداد النظام.
- لا تنشر بيانات الطلاب أو ملفات قاعدة البيانات للعامة.
- اختر صلاحيات الوصول بعناية عند نشر التطبيق.
- اختبر تسجيل الدخول والحضور والأرشفة قبل الاستخدام الفعلي.

## ملاحظة مهمة

GitHub مخصص لحفظ الأكواد وإدارة الإصدارات. تشغيل التطبيق يتم من خلال Google Apps Script، وليس من GitHub Pages مباشرة.
